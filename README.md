# ChatGeePeeTee
discord bot thats litterally just an LLM

hosted on my PC manually, so best believe its not currently active

## Setup

1. `python -m venv .venv` and activate it
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in your Discord token and API keys
4. `python chatpgtbotdiscord.py`
